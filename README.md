# infopesantren.online 🕌

Portal warta berita pesantren modern, responsif, dan independen yang menyajikan khazanah keilmuan Islam, informasi beasiswa santri, kajian turats & kitab kuning, agenda bahtsul masail nasional, serta fitur komentar interaktif dan integrasi media sosial.

---

## 🚀 Fitur Utama

- **Desain Modern & Responsif**: Tampilan bertema editorial islami dengan tipografi *Newsreader* dan *Plus Jakarta Sans*.
- **Pita Waktu Sholat & Penanggalan Hijriah**: Jadwal sholat harian untuk berbagai kota di Indonesia serta kalender Hijriah.
- **Running Ticker Warta Terkini**: Menampilkan update warta breaking news secara dinamis.
- **Kolom Komentar Interaktif**:
  - Pilihan peran pembaca (*Santri*, *Alumni*, *Ustadz/Ustadzah*, *Wali Santri*, *Pembaca Umum*).
  - Balasan komentar bertingkat (*nested replies*).
  - Like/upvote komentar dan filter komentar terbaru/terpopuler.
  - Penyimpanan data lokal (*localStorage*).
- **Integrasi Media Sosial**:
  - Tombol berbagi 1-klik ke WhatsApp, Telegram, X (Twitter), Facebook, dan salin tautan.
  - Kanal komunitas resmi (Saluran WhatsApp, Grup Telegram, YouTube Khazanah, Instagram).
  - Buletin mingguan santri.
- **Fitur Pembaca Modern**:
  - *Audio Reader* (Text-to-Speech) untuk mendengarkan artikel warta.
  - Pengatur ukuran teks baca (`A`, `A+`, `A++`).
  - Simpan artikel favorit (*Bookmarks*).
  - Form Jurnalisme Warga (*Kirim Berita & Rilis Pondok*).
  - Kalender agenda pesantren & bahtsul masail nasional.

## 💻 Cara Menjalankan Secara Lokal

1. **Clone repository ini**:
   ```bash
   git clone https://github.com/USERNAME_ANDA/infopesantren-online.git
   cd infopesantren-online
   ```

2. **Instal dependensi**:
   ```bash
   npm install
   # atau menggunakan pnpm / bun / yarn
   ```

3. **Jalankan server pengembangan**:
   ```bash
   npm run dev
   ```
   Buka browser di `http://localhost:3000` atau port yang ditampilkan di terminal.

4. **Build untuk produksi**:
   ```bash
   npm run build
   ```
